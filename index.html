Formatting tips
**bold** and *italic* · (reminder text) is italic automatically · ability words like "Landfall —" are italicised automatically · start a line with "- " for a • bullet · type " -- " for a long dash —.
Planeswalker: one ability per line, e.g. "+1: Draw a card." Saga: "I — …", "II, III — …". Put loyalty or defense in the P/T box.
The rules text does not fit, even at the smallest size. Shorten it, remove flavor text, or set a text size.

Chrome/Edge: pick a file once and every change is written to it automatically.
Sync between devices with a GitHub Gist
Create a GitHub token with only the "gist" permission (github.com → Settings → Developer settings → Personal access tokens), paste it here, then Push on one device and Pull on another. The token is stored only in this browser.

Print sheet (PDF)

Use "+ Add to print sheet" under the card, or the − / + under each saved card, to choose how many copies print.
Double-faced cards print their real back face. In duplex mode, single-faced cards get your back image (or a plain proxy back). Print duplex with "flip on long edge".
9 cards per page at real size (63×88 mm, 300 dpi). When printing the PDF choose Actual size / 100%, not "Fit to page".
